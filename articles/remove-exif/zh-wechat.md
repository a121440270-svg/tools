## 一张随手拍的照片，可能比你的朋友圈更"健谈"

周末在闲鱼挂了个闲置，拍照上传；给客户发了一张合同扫描件；在论坛发帖求助，顺手贴了张截图。

图片看起来只是图片。但一张由手机或相机拍出来的 JPEG，文件头里往往还附着一整页"说明书"：拍摄时的 GPS 经纬度、手机或相机的品牌型号、精确到秒的时间、当时的作者与版权信息，有时甚至还有一张你自己都没见过的原始缩略图。

这些东西叫 EXIF。它本身不是病毒，也不是后门，但它是一种**默认替你说出、你又看不见的信息**。

{{IMG:cover}}

## EXIF 到底是什么

EXIF 是 Exchangeable Image File Format 的缩写，可以理解为"写进图片文件里的一张信息表"。相机在按下快门的那一刻，会自动把当时的条件记录下来：

- **拍摄参数**：光圈、快门、ISO、焦距、曝光补偿、白平衡
- **设备信息**：厂商、机型、镜头、部分机型还有序列号
- **时间**：拍摄日期与时间，精确到秒，通常还带时区
- **位置**：GPS 纬度、经度、海拔，有的还有拍摄方向
- **作者与版权**：Artist、Copyright 字段，很多相机允许你提前填写
- **处理痕迹**：使用的软件、编辑历史
- **内嵌缩略图**：一张小尺寸预览，用来在图库和文件管理器里快速显示

它存在的理由很正当：让你按机型筛照片、按拍摄地整理旅行相册、查一张照片到底是不是原片。问题在于，**这些字段并不区分"你给自己看"和"你发给别人看"**。

## 为什么它值得你花两分钟在意

**第一，位置是真实的。** 家里拍的照片带 GPS，发到二手平台、租房群、业主论坛，等于把住址标在了地图上。注意，EXIF 记录的是拍摄点，不是你发帖的地点。

**第二，时间是真实的。** 精确到秒的时间能对上你的作息：几点在家、几点在公司、哪天出差。

**第三，设备是真实的。** 机型、镜头、序列号，能把不同帖子里"同一个人"的账号串起来。

**第四，一致性会露馅。** 用 A 手机拍、B 手机发，元数据里却写着 C 型号，这类矛盾在纠纷、维权、二手交易里足够让人起疑。

需要说清楚的是：**不同平台的处理方式不一样**。不少社交平台在上传时会重新编码并剥离元数据，但"发送原图"、邮件附件、网盘直链、部分论坛的上传通道，通常是原样搬运。所以最稳妥的判断标准不是"平台会不会处理"，而是**你手上这个文件本身干不干净**。

## 先看清楚：图片信息查看器

在删之前，值得先知道自己的照片里到底有什么。

打开 [图片信息查看器](https://onlitools.com/image-info)，把图片拖进页面，它会在本地解析出文件尺寸、格式、体积、宽高比，以及可读取的全部 EXIF 字段，并按 IFD0 / 缩略图 / EXIF / GPS / XMP 分组列出。

{{IMG:info}}

整个过程在浏览器里完成，图片不会上传到服务器——这一点对"检查隐私"这件事尤其重要：你总不能为了确认照片安不安全，先把它上传给一个陌生服务器。

我拿一张带 GPS 的样张试了一下，工具报告"发现 35 个元数据字段"，并直接点出五类风险：GPS 位置、相机或设备信息、拍摄日期或时间、作者/版权/备注、嵌入式缩略图。

## 再动手：三步移除 EXIF

工具地址：https://onlitools.com/remove-exif

{{IMG:detect}}

**第一步，拖入图片。** 打开页面，点击或将图片拖到虚线框里，支持一次选多张。页面会立刻扫描每张图，显示它发现了多少个元数据字段，并把命中的风险类别列出来。

{{IMG:done}}

**第二步，选输出格式。** 可选 JPG、PNG、WebP。这里要说清楚它的原理：**它不是把 EXIF 段"打个叉"，而是把像素重新编码成一张新图**，所以旧文件里的元数据不会跟着过去。代价是画质与体积会变——我那张 309.1 KB 的样张，清理后是 413 KB，因为重新编码用的是编码器的默认质量。

**第三步，点"移除元数据"，然后下载。** 处理完成后每张图会显示"已完成"和下载按钮，文件名自动加上 `-clean` 后缀，比如 `IMG_2026.jpg` 变成 `IMG_2026-clean.jpg`，不会覆盖你的原图。

验证也很简单：把清理后的图再丢回[查看器](https://onlitools.com/image-info)，35 个字段归零，GPS 段不存在。

几个实际使用中的注意点：

- **透明图不要转 JPG**。PNG 的透明区域在 JPG 里会变成白底，需要保留透明度就输出 PNG 或 WebP。
- **批量处理更省事**。一次拖入十几张，比一张张点快得多，全部处理完再统一下载。
- **清理不可逆**。元数据一旦被抹掉，拍摄参数也就没了，需要留档的原片请先备份。

## 反过来：需要"改"而不是"删"的时候

有些场景你要的不是清空，而是修正。比如：

- 相机的时间设错了，想让照片回到正确的日期
- 二手转卖前，抹掉 GPS 但保留拍摄参数
- 给一批作品统一写入作者和版权
- 照片是从别处导出的，作者字段还挂着上一个人的名字

这时候用 [EXIF 编辑器](https://onlitools.com/exif-editor)。

{{IMG:editor}}

它支持编辑拍摄时间、相机厂商、相机型号、作者、版权、图片描述，以及 GPS 纬度、经度、海拔（可以在地图上直接选点）。规则很直白：**留空即移除该字段**；GPS 经纬度必须同时填写；作者和描述支持中文，相机与版权字段只支持 ASCII。目前仅支持 JPEG，处理同样在本地完成。

一个常见组合：先用查看器确认原始信息，再用编辑器把能识别身份的部分删掉、把想保留的拍摄参数留下，最后才发出去。
