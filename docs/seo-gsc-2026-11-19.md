### 根因 A：query string 污染 canonical / hreflang（104 页）— 已修复

`/image-compress?size=50`、`/send-script-to-remote-user?share=abc` 等工具状态 URL，
其 canonical 和 hreflang 曾带上完整 query：

```
修复前： <link rel="canonical" href="https://onlitools.com/image-compress?size=50">
         hreflang 也出现 ...?size=50 版本 → 每个状态 URL 自成一页
```

`useToolSeo.ts` 里 `switchLocalePath()` 会保留当前 query，又被写进 canonical/alternate。
**修复**：新增 `stripQuery()`，只作用于派生出的 canonical / hreflang；
显式传入的 `canonical` / `alternates` 不受影响（`composables/useToolSeo.ts`）。

**部署后验证**（`verify-deploy.mjs`）：

| URL | 修复后 canonical | canonical 数量 |
|---|---|---|
| `/image-compress?size=50` | `https://onlitools.com/image-compress` | 1 |
| `/send-script-to-remote-user?share=abc` | `https://onlitools.com/send-script-to-remote-user` | 1 |

### 根因 B：私有路由 SSR 为空壳，noindex 只在 hydration 后才注入 — 已修复

`/auth/login` 等路由是 `ssr: false`，Googlebot 拿到的 HTML 里没有
`<meta name="robots" content="noindex">`，因此出现在「已抓取 - 尚未编入索引」名单。
**修复**：新增 `server/middleware/noindex-private-routes.ts`，在 Worker 层统一注入
`X-Robots-Tag: noindex, nofollow, noarchive`（覆盖 admin/auth/profile/pay/blog/post/prompts/shares）。

**部署后验证**：`/auth/login` → HTTP 200，`x-robots-tag: noindex, nofollow, noarchive` ✅

### 根因 C：16 个 5xx — 已自愈

示例 URL 复查：`/fr/blog/12-ge-css-yang-shi-ge-li-ji-qiao-220` → 301 到
`/blog/12-css-style-isolation-techniques-220`（HTTP 200，正常页面），
`/blog/mobile-touch-event-optimization-strategies-234` → 301 到正确 slug。
判断为 11-13/14 的短暂故障，现已恢复，无需改动代码。
